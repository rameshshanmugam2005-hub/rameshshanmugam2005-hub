## 🚌 Transit AI

### Real-Time Public Transit & AI Assistant

Transit AI is a **full-stack public transit web application** designed to provide real-time transit information and AI-powered assistance.

### ✨ Features

- 🚌 Real-time transit information
- 🗺️ Routes and schedules
- 📡 Backend API integration
- 👥 Passenger occupancy monitoring
- 🚦 Congestion visualization
- 🤖 AI-powered transit assistance
- 🎫 QR ticket validation
- 📊 Dynamic data updates
- ⚡ Bandwidth-efficient polling
- 📱 Responsive user interface
